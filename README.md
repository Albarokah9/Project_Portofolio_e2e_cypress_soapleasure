# 🛁 Project Portfolio: E2E Testing - Soapleasure Website

Proyek portofolio ini mendemonstrasikan otomatisasi pengujian *End-to-End* (E2E) untuk fungsionalitas utama website [Soapleasure.com](https://soapleasure.com/) menggunakan **Cypress**.

---

## 💻 Tech Stack & Tools
* **Framework**: Cypress
* **Reporting**: Cypress Mochawesome Reporter (Menghasilkan laporan HTML interaktif)
* **CI/CD**: GitHub Actions (Otomasi pengujian)
* **Website Target**: Soapleasure.com
* **Manajemen Test Case**: ClickUp

## 🎯 Fokus Test Cases
Proyek ini mencakup otomatisasi untuk alur pengguna kritis berikut:
* Register
* Login
* Logout
* Forgot Password
* Checkout

## 🚀 Setup & Installation

Ikuti langkah-langkah di bawah ini untuk menjalankan proyek secara lokal.

### Prerequisites
Proyek ini menggunakan Yarn sebagai *package manager*. Pastikan Anda memiliki:
* **Node.js** (Versi 16 atau lebih baru. Direkomendasikan Node.js 20 LTS)
* **Git**
* **Yarn** (Jika belum terinstal secara global, jalankan: `npm install --global yarn`)

### 1. Clone Repository
```bash
git clone [https://github.com/Albarokah9/Project_Portofolio_e2e_cypress_soapleasure](https://github.com/Albarokah9/Project_Portofolio_e2e_cypress_soapleasure)
cd Project_Portofolio_e2e_cypress_soapleasure
